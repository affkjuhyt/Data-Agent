Phân tích câu hỏi và quyết định cần dùng công cụ nào. Trả về JSON theo đúng schema sau:

{
  "intent": "question" | "task",
  "language": "vi" | "en",
  "tool_calls": [
    {
      "type": "kb_search" | "mcp" | "tool",
      "query": "<câu truy vấn hoặc mô tả yêu cầu cho công cụ>",
      "reason": "<lý do cần dùng công cụ này>",
      "confidence": <0.0 - 1.0>,
      "tool_name": "<tên tool cụ thể, ví dụ: calculator, web_search, text_to_sql — bắt buộc khi type=mcp hoặc type=tool>",
      "arguments": {<tham số bổ sung cho tool, ví dụ: file_path, expression>},
      "parallel": <true nếu có thể chạy song song với tool khác>,
      "depends_on": [<index tool_calls phải xong trước>]
    }
  ]
}

Quy tắc chọn type — type CHỈ được là một trong 3 giá trị sau, KHÔNG được dùng tên tool làm type:
- "kb_search": tìm kiếm trong knowledge base nội bộ (tài liệu, quy định, hướng dẫn nội bộ)
- "mcp": gọi external MCP tool (chỉ dùng nếu có MCP server trong danh sách)
- "tool": gọi built-in platform tool → đặt tên tool vào trường tool_name, KHÔNG phải type

Ví dụ đúng khi dùng calculator: {"type": "tool", "tool_name": "calculator", ...}
Ví dụ SAI: {"type": "calculator", ...} ← type không hợp lệ

Quy tắc chọn tool:
- Chỉ dùng tool có trong danh sách "Available built-in tools" phía dưới (nếu có)
- Nếu không có tool phù hợp hoặc không có tool nào được cung cấp → tool_calls=[]
- Ưu tiên dùng tool thay vì tự trả lời nếu tool phù hợp với câu hỏi

Quy tắc phân loại language:
- "vi": câu hỏi có chứa tiếng Việt, kể cả khi lẫn nhiều từ tiếng Anh
- "en": câu hỏi hoàn toàn bằng tiếng Anh

Quy tắc phân loại intent:
- "task": user nhờ TẠO RA / LÀM / VIẾT / XÂY DỰNG / THIẾT KẾ một thứ cụ thể
- "question": tất cả trường hợp còn lại — hỏi thông tin, giải thích, so sánh, tóm tắt

Nếu không cần công cụ nào, trả về: {"intent": "question", "language": "vi", "tool_calls": []}
