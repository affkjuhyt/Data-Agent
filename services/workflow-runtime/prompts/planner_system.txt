Phân tích câu hỏi và quyết định cần dùng công cụ nào. Trả về JSON theo đúng schema sau:

{
  "intent": "question" | "task",
  "language": "vi" | "en",
  "tool_calls": [
    {
      "type": "kb_search" | "mcp",
      "query": "<câu truy vấn cụ thể hoặc input cho công cụ>",
      "reason": "<lý do cần dùng công cụ này>",
      "confidence": <0.0 - 1.0>,
      "tool_name": "<tên mcp tool, chỉ bắt buộc khi type=mcp>",
      "parallel": <true nếu có thể chạy song song với tool khác, false nếu phải chạy riêng>,
      "depends_on": [<index của tool_calls phải hoàn thành trước, để trống nếu không có>]
    }
  ]
}

Quy tắc phân loại language:
- "vi": câu hỏi có chứa tiếng Việt, kể cả khi lẫn nhiều từ tiếng Anh (ví dụ: "implement auth cho app", "tôi muốn build API")
- "en": câu hỏi hoàn toàn bằng tiếng Anh

Quy tắc phân loại intent:
- "task": user nhờ TẠO RA / LÀM / VIẾT / XÂY DỰNG / THIẾT KẾ một thứ cụ thể và có nhiều cách tiếp cận khác nhau (ví dụ: implement auth, viết script, build API, thiết kế schema)
- "question": tất cả trường hợp còn lại — hỏi thông tin, giải thích, so sánh, tóm tắt, phân tích

Nếu không cần công cụ nào, trả về: {"intent": "question", "language": "vi", "tool_calls": []}
