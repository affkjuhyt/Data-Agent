## 2. Hệ thiết kế: `frontend/src/design-system/`

- `tokens.css`: biến CSS trùng tên code syntax trong Figma (`--background`, `--card`, `--primary`,
  `--space-xl`, `--radius-lg`, `--shadow-md`…), lớp chữ `.da-heading-1`, `.da-body-small`… mỗi lớp một
  text style Figma, và chế độ `data-density="compact"`.
- Tiện ích Tailwind trên cùng biến: `bg-card`, `text-muted-foreground`, `border-border-strong`,
  `rounded-lg`, `shadow-md`. Khoảng cách mang tiền tố `da-` (`p-da-xl`, `gap-da-md`) vì `--spacing-xl`
  trần sẽ đè thang kích thước của Tailwind (`max-w-xl` thành 16px).
- Không viết mã màu hex trong component; thiếu token thì thêm vào Figma rồi vào `tokens.css`.
- `icons/`: 61 icon SVG của Figma, tải nguyên vẹn. `<Icon>` vẽ SVG với nét theo `currentColor`.
- Mỗi component một file, ghi node Figma trong chú thích đầu file: Button, Badge, StatusDot, Avatar,
  Input, Field, Select, Checkbox, Radio, Toggle, Tabs, NavItem, Menu, Tooltip, Toast, ConfirmDialog,
  Pagination, SkeletonRow, EmptyState, KpiCard, DataFreshness, AgentChip, RunStep, SuggestionChip,
  Composer. Hành vi bàn phím và trạng thái theo "Đặc tả cho dev" có test ở `designSystem.test.tsx`.

## 3. Khung trang và điều hướng v3.1

`components/shell/`: `AppShell` (thanh trên 56px cố định, rail 208px, chỉ vùng chính cuộn), `AppTopBar`
(sáu khu vực, chọn Data Space, ⌘K, số Cần bạn), `SideRail`, `PageHeader`, `CommandPalette`.

| Khu vực | URL | Màn hiện có |
| --- | --- | --- |
| Trang chủ | `/home` | Trang chủ mới (`features/home`) |
| Cần bạn | `/needs-you` | Hàng chờ duyệt HITL (ReviewCenter) |
| Agents | `/agents/team`, `/runs`, `/evaluate`, `/orchestration` | Agent runtime, trace, playground, workflow |
| Phân tích | `/analysis/ask`, `/sessions`, `/dashboard` | Hỏi đáp, hội thoại, dashboard |
| Dữ liệu | `/data` | Knowledge Ops Center |
| Quản trị | `/admin/<mục>` | Các mục Settings cũ |

Đường dẫn của IA cũ (`/ask`, `/build/agents`, `/ops/traces`, `/settings/api`…) được chuyển tiếp ở
`resolveRoute` (`AppStateContext.tsx`). Mọi người vào Trang chủ khi mở ứng dụng.

## 4. Dữ liệu cho màn mới

API trong tài liệu thiết kế là `/v1/...` (inbox, runs, sources, metrics…), backend chưa phục vụ. Màn mới
chỉ vẽ khối có nguồn dữ liệu thật; khối chưa có nguồn thì chưa vẽ, không dùng số giả. Trang chủ hiện có
lời chào, ô hỏi (chuyển câu hỏi sang Phân tích bằng `?q=`) và "Cần bạn quyết định" từ
`/api/reviews/pending`.
